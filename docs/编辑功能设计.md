# 网页端直接修改文件 — 设计存档

> 状态：已实现（P0 编辑 + P1 新建题解/新建 .config.json）。本文件为设计记录，非实现代码。
> 背景约束：编辑只发生在**本地** `~/Github/Code`；`sync.sh` 将本地文件**单向完整覆盖**服务器对应文件；服务器上运行的 dashboard 不带写能力，不存在"通过服务器网页改文件"的场景。

## 1. 部署模型与写能力开关

```
node server.js            → 纯只读（现状；服务器部署照旧用这条）
node server.js --edit     → 开启写接口（仅本地如此启动）
```

- 写请求须**同时**满足：`--edit` 已开启 **且** 来源为回环（`req.socket.remoteAddress` ∈ `127.0.0.1`/`::1`/`::ffff:127.0.0.1`）。
  - `--edit` = "我授权这台机器可写"；回环 = "只有这台机器本机的浏览器能写"（`--edit` 开着但端口暴露局域网时，其它设备仍只读）。
- 服务器侧零改动：sync.sh 原样覆盖代码，服务器启动不带 `--edit` → 写接口 403、UI 无编辑入口。
- 前端能力探测：`GET /api/capabilities` 返回 `{edit: bool}`（渲染期查询一次）；「编辑」按钮仅在 `edit && 文件属可写区` 时出现。

## 2. 可修改文件清单（区域白名单）

| 类别 | 范围 | UI 入口 | 编辑形态 |
|---|---|---|---|
| A. 题解源码 | 6 平台 `.cpp/.py`（非 `Template/` 下，排除 `Template/md2pdf.py`） | 题目卡片 → 代码 modal | CodeMirror（cpp/python mode） |
| B. 模板文档 | `Template/*.md` | Template 文档卡 | CodeMirror（markdown mode），保存后自动重渲染 |
| C. 比赛元数据 | 各 contest 目录 `.config.json` | contest 卡 hover「⚙」 | 结构化表单（url + cnt），不裸改 JSON |

后端判据（PUT/GET 通用）：
```
可写 ⟺ (非 Template 下 .cpp/.py) || (Template/*.md) || (basename == .config.json)
```
永久只读（UI 不显示、后端 403）：`server.js`、`sync.sh`、`index.html`、`style.css`、`app.js`、`AGENTS.md`、`Template/pdf/*`、`Template/md2pdf.py`、`.git/`、`.reasonix/`、其它未知扩展名与二进制。
（`sync.sh` 覆盖方向若反转是工作流纪律问题，非代码可防。）

## 3. 后端 API

```
GET /api/capabilities          → {edit: bool}
GET /api/file?path=<相对ROOT>   → 文本白名单读取；返回 {content, mtime, writable}
PUT /api/file  body            → {path, content, baseMtime}（改已有文件）
POST /api/file body            → {path, content}（新建：题解 .cpp/.py 与 .config.json）
  成功 200 {ok:true, mtime}；PUT baseMtime 与磁盘不符 → 409 {error:'CONFLICT', mtime}；
  baseMtime 传 null = 强制覆盖（仅限 409 弹窗用户确认后）；
  POST 目标已存在 → 409 {error:'EXISTS'}。
```

PUT/POST 校验链（每步不过即 4xx）：
1. `--edit` + 回环双门禁（否则 403）；
2. `path` decode → `path.resolve(ROOT, path)` 必须落在 ROOT 下（复用现有 jail）；
3. 黑名单：`.git/`、`.reasonix/`、根级 `server.js/sync.sh`、页面资源、`Template/pdf` 等（区域白名单反向即黑名单）；
4. PUT：目标文件必须**已存在**；POST：目标必须**不存在**（存在 → 409），且父目录存在；
5. 大小上限 256KB；内容含 NUL 判二进制拒绝；
6. `.json` 保存前 `JSON.parse` 语义校验（防 `.config.json` 写坏拖垮 dashboard）；
7. PUT 乐观锁：`baseMtime !== 磁盘 mtime` → 409（防多窗口/外部编辑器盲覆盖）。

写入方式：同目录临时文件 + `fs.renameSync` **原子替换**（中断不产生半截文件）；写失败不碰原文件；成功后 `invalidateCache()`（fs.watch 会再触发一次 SSE，幂等无害，不做 suppress）。

## 4. 前端交互

- **代码查看 modal**：查看/编辑**双态**（同一 modal）。查看态工具栏 `[行号][换行][复制][下载]`；编辑态 `[取消][保存]`，隐藏查看态专属按钮（"复制 full"语义在未保存内容下会混淆）。
- **入口按钮**：`editable/writable` 为真才显示「编辑」。
- **CodeMirror 5（CDN，懒加载）**：点「编辑」时才注入 css/js；mode 映射 `.cpp→text/x-c++src`、`.py→python`、`.md→markdown`、`.json→javascript`；行号 `lineNumbers:true`；换行跟随现有 toggle 语义；亮暗主题用自定义 CSS 变量覆盖，不引额外主题文件。CM 实例**复用**（切文件 `setValue` + 换 mode），查看态容器与编辑容器分居 modal-body 内互不干扰。
- **脏标记**：改动后工具栏显示「● 未保存」；点「保存」前弹确认提醒（已移除 Ctrl/Cmd+S 快捷键，避免误触）；关闭 modal / 刷新页面前未保存 → 确认拦截。
- **保存**：成功 → toast「已保存 HH:MM:SS」+ 回填新 `mtime`；409 → 弹窗「文件已在别处被修改：[载入磁盘版] / [仍然覆盖]」。
- **模板文档**：查看态渲染 markdown；保存成功后自动重新 fetch 并渲染（所见即所得），编辑/预览实时分栏列为 P2。
- **.config.json 表单**：`⚙` → `GET /api/file` 读现值 → 表单（url 校验 `new URL`、cnt 数字）→ PUT → SSE `refreshData` 自动刷新卡片。域名语义提示：XCPC 的 qoj.ac/vjudge.net 链接分发由 url 决定；cnt 改大=新增待补题空槽。
- **SSE 协同**：`reload` 只触发 `refreshData()` 不重建 modal → 编辑不被打断；预留全局 `editing` 标志，防未来 reload 升级为整页刷新时丢稿（编辑中只 toast 不刷新）。

## 5. 数据一致性
- 保存后 `invalidateCache()` → 列表/链接/题数即时更新；
- 编辑题解内容不影响 solved 判定（`getSolved` 只看 stem）；
- 编辑 `.config.json` → JSON 校验后保存即生效。

## 6. 非目标（P0/P1 不做）
重命名 / 删除（依赖 git 管理，删除误操作不可逆）；二进制；多人协同；实时预览分栏；保存后 `g++` 编译校验（远期）。

## 7. 新建（已实现 P1）
- **新建题解**：未解决题 hover「+」→ 表单（题号预填 + cpp/py 选择 + 路径预览）→ `POST /api/file` 建骨架（cpp 用 `#include <ihxnan>` + `solve()`；py 用输入辅助骨架）→ 自动 `showCode` 打开（可立即编辑）→ `refreshData` 让卡片转「已解决」。文件名 stem 即题号（`A.cpp`/`10.cpp`/`P10446.cpp`），与 `getSolved` 识别规则一致。
- **新建 .config.json**：⚙ 对**所有**有 `dir` 的 contest 卡显示；打开时 `GET /api/file` 404 → 「新建」模式（预填 `c.url`/`c.total`），保存走 `POST`；POST 撞 409 EXISTS（竞态）→ 询问后转覆盖 PUT。
- 后端 `isCreatableRel`：可写区域内**仅**题解 `.cpp/.py`（stem 限 `[A-Za-z0-9]+`）与 `.config.json`；`Template/*.md` 不允许新建（避免乱建文档）。

## 8. 实现范围
- `server.js`：`--edit` 解析、`GET /api/capabilities`、`GET/PUT/POST /api/file`、`GET /api/code` 响应增 `mtime`/`editable`。
- `index.html`：modal-header「编辑」按钮、编辑容器（textarea 挂点）、config 表单 modal、toast 容器。
- `app.js`：CM5 懒加载、双态切换、脏标记/保存确认、409 弹窗、config 表单、toast、`editable` 门控、`editing` 标志。
- `style.css`：CM 亮暗适配、编辑态布局、表单与 toast 样式。

## 9. 验证口径
1. 无 `--edit`：UI 无编辑入口，`PUT /api/file` 403；
2. `--edit` + 回环：题解/模板/`.config.json` 可存；页面资源与区外文件 403；不存在文件 404；
3. `baseMtime` 过期 → 409，强制覆盖（null）可写；
4. `.json` 非法内容被拒；
5. 保存后 `/api/data` 内容更新（`.config.json` 改 cnt → 卡片槽位变化）；
6. 非回环来源（模拟）403。
